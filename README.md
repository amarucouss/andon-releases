# andon-releases
Release builds of Andon, a desktop panel to run Minecraft servers. Installed copies update themselves from here.

- **Linux:** `andon-linux-amd64`. An installed copy finds each release through the signed `manifest.json` and updates itself.
- **Windows:** `andon-windows-amd64.exe`, from 0.1.2 on. It is cross-compiled on Linux and has not yet been run on a Windows machine. It does not update itself yet: download the new one from the [latest release](https://github.com/amarucouss/andon-releases/releases/latest), whose page gives its SHA-256.
